# Release OmniFysics-Captioner

This release contains the OmniFysics-Captioner project documentation, the
Captioner and PPM inference entrypoints, and the public OPC caption-generation
evaluation entrypoint.

Model weights are published at:

https://huggingface.co/Fysics-AI/OmniFysics-Captioner

The repository keeps deployment and evaluation code under `inference/` and
`evaluation/`; private benchmark answers, credentials, machine-specific
paths, and internal run artifacts are excluded.
